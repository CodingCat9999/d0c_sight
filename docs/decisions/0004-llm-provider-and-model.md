# 0004. LLM 공급사와 모델 선택

- 상태: 채택됨 (잠정)
- 날짜: 2026-09-10

## 배경

Phase 2 는 에러 메시지에 구조화된 진단을 내는 첫 LLM 계층이다. 공급사와 모델을 골라야
하는데, **평가셋이 아직 없다**(Phase 3). 품질을 측정할 수 없는 상태에서 고르는 선택이다.

## 결정

**Google Gemini API 무료 티어, Flash 계열.** 기본 모델은 `gemini-3.7-flash`.

**공급사와 모델을 코드가 아니라 설정으로 분리한다.** `LlmConfig` 가 공급사·모델·폴백
후보·thinking 예산을 들고, 환경변수로 덮어쓸 수 있다. Phase 9 모델 라우팅이 이 추상화를
그대로 쓴다.

**결과에 공급사와 모델을 기록한다.** `GenerationRecord` 가 `provider` / `model` /
`attempted_models` / 토큰 / 지연을 남긴다. 무엇이 답했는지 모르면 나중에 비교할 수 없다.

**thinking 예산을 0 으로 명시한다.** 스키마의 `reasoning` 필드가 이미 명시적 추론을
담는다. 둘 다 켜면 같은 추론에 토큰이 이중으로 나가고, 무료 티어에서는 그것이 곧
쿼터다. 실측상 `thinking_config` 를 지정하지 않으면 모델에 따라 526~2,122 thinking
토큰이 추가로 나갔다.

**프롬프트 방식은 zero-shot 하나로 고정한다.** few-shot 예시를 넣지 않는다.

## 대안

### Anthropic Claude / OpenAI

기각 — 사용자가 무료 티어 제약 아래 Gemini 를 지정했다. 공급사 추상화가 있으므로
Phase 9 에서 다른 공급사를 붙일 수 있다. 다만 **인터페이스는 아직 검증되지 않았다**
(ADR 0002): 구현체가 하나뿐이라 이 모양이 옳은지 알 수 없다.

### `gemini-3.8-flash` (최신)

기각 — 실측에서 **다섯 번 중 세 번 503** 이 났고, 성공한 호출도 18초가 걸렸다.
무료 티어에서 부하가 가장 큰 모델로 보인다.

### `gemini-2.5-flash`

**선택 불가.** 404 와 함께 `"no longer available to new users. Please update your code
to use models/gemini-3.6-flash"` 를 반환한다. 모델 목록에 나타난다고 쓸 수 있는 것이
아니다.

### `gemini-flash-latest` (별칭)

기각 — 별칭은 조용히 움직인다. CI 액션 버전에서 같은 교훈을 얻었다(`setup-uv@v10` 이
존재하지 않아 첫 CI 가 깨졌다). 재현성을 위해 버전을 고정한다.

### `gemini-3.1-flash-lite`

**Phase 3 비교 후보로 기록만 한다.** 실측에서 thinking 토큰 0, 지연 3.93초로 가장
저렴했다. 품질은 평가셋 없이 판단할 수 없다.

### zero-shot 대신 few-shot / CoT

**Phase 3 이후로 미룬다.** 지금 비교하면 평가 기준이 없어 감으로 판단하게 되고, 그
판단이 이후 결정의 근거로 굳어진다.

## 결과

### 얻는 것

- 비용 0 으로 Phase 2~3 을 진행할 수 있다
- 공급사·모델이 설정이므로 Phase 9 에서 코드를 고치지 않고 바꿀 수 있다
- 결과에 모델이 기록되어 과거 결과와 비교 가능하다

### 감수하는 것

- **무료 티어는 입출력이 모델 개선에 사용될 수 있다.** 따라서 **공개 문서로만
  테스트하고 비공개 데이터를 넣지 않는다.** PostgreSQL 공식 문서는 공개 자료다.
  이 제약은 Phase 3 평가셋에도 적용된다
- 가용성이 불안정하다. 503 이 일상적으로 발생한다(ADR 0006 의 폴백이 이를 다룬다)
- **모델 선택이 측정에 근거하지 않는다.** 지연과 가용성만 보고 골랐다

### 언제 재검토하는가

- **Phase 3 평가셋이 생긴 직후.** 그때 `gemini-3.7-flash` / `gemini-3.5-flash` /
  `gemini-3.1-flash-lite` 를 같은 기준으로 비교하고, 이 ADR 을 대체하는 새 ADR 을 쓴다
- 무료 티어 제한이 작업을 막을 때 — 유료 전환 또는 공급사 변경
- thinking 을 끈 것이 품질을 떨어뜨린다고 **측정될 때**
